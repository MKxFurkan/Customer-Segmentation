
# Customer Segmentation using K-Means Clustering

## Project Overview
This project aims to segment customers into different groups based on their purchasing behavior and other characteristics using unsupervised machine learning.

## Dataset
- Customer Personality Analysis
- 2,240 records
- 29 columns
